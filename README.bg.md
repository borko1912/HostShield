---

Сайтовете ти са в cPanel / SPanel / Plesk / DirectAdmin акаунт. Нямаш root, така че сървърни firewall-и и агенти отпадат.
Плъгините за сигурност пазят по един WordPress — и падат заедно с него, когато бъде хакнат.

HostShield е едно малко PHP приложение, което качваш веднъж. То пази **всеки сайт в хостинг акаунта** (WordPress, Laravel,
Joomla, Drupal, PrestaShop, OpenCart, Magento или обикновен PHP) отвън: firewall, който се изпълнява преди всеки сайт,
нощни бекъпи с възстановяване с един клик, наблюдение на файловете, което хваща уеб шелове, и одит на сигурността с оценка.

Направен е, след като сайтовете на автора бяха хаквани отново и отново. Оттогава работи на тях.

## Какво получаваш

| | |
|---|---|
| 🛡 **Firewall (WAF)** | Изпълнява се преди всяка PHP заявка на всеки сайт. Спира SQL injection, XSS, path traversal, отдалечено изпълнение на код, скенери и налучкване на пароли. Банва повторните нарушители (1 ч → 2 ч → 4 ч … 7 дни). Започва в режим **„само запис“**, за да маркираш фалшивите тревоги с един клик, преди да включиш блокирането. |
| 🚫 **Спира уеб шеловете** | PHP никога не се изпълнява от папките за качване. По желание **Lockdown**: изпълняват се само одобрени от теб скриптове — току-що качен шел просто не тръгва. |
| 💾 **Бекъпи** | Файлове + бази всяка нощ. Дневни / седмични / месечни копия. Проверка на checksum преди всяко възстановяване. Копия в **S3, Backblaze B2, Cloudflare R2, Wasabi, MinIO или FTP** — и изтегляне обратно оттам, ако загубиш сървъра. |
| ⏪ **Възстановяване с един клик** | Всичко, само файлове или само база. Първо прави предпазен бекъп, показва страница „поддръжка“ докато трае и маха файловете, добавени от нападателя. |
| 🔍 **Скенер** | Следи всеки файл с код и всяко качване. Подписи на известни шелове и обфускация. **Ядрото и плъгините на WordPress се сравняват с официалните checksums от wordpress.org** — хваща се дори един променен файл. Карантина с връщане. |
| 📋 **Одит на сигурността** | 20+ проверки на сайт с оценка A–F: достъпни `.env` / `.git` / бекъпи, изтичащ SSL, пренасочване към HTTPS, security headers, стар WordPress, debug режим, права на файловете. За всеки проблем има инструкция. |
| 🔔 **Известия** | Имейл (PHP mail или SMTP), Telegram, Discord, Slack или webhook: сайт не работи, изтичащ SSL, подозрителен код, неуспешен бекъп, нов вход. |
| ⚙️ **Настройка без конфигурационни файлове** | Уеб инсталаторът намира сайтовете в акаунта и сам чете достъпа до базите от конфигурацията на всяко приложение. |
| 🌍 **Български и английски** | |

## Инсталиране (5 минути)

**Изисквания:** PHP 8.1+ с `zip`, `mysqli`, `curl` (стандартни на всеки хостинг). Cron задача всяка минута.

1. **Изтегли** последния zip от [Releases](https://github.com/borko1912/hostshield/releases).
2. **Създай поддомейн** за таблото, напр. `shield.example.com`, и **качи** съдържанието на zip-а в папката му
   (File Manager → Upload → Extract).
3. **Отвори** `https://shield.example.com` — инсталаторът проверява сървъра, избира папка за данни извън публичната папка,
   създава профила ти и показва намерените сайтове. Натисни **Инсталиране**.
4. **Cron:** таблото показва точната команда за твоя сървър. Постави я в *Cron Jobs → всяка минута*.
5. На всеки сайт натисни **Включи firewall-а**, после **Бекъп сега**. Включи **2FA** в *Настройки → Сигурност*.

Списъкът за настройка на началната страница те води през останалото.

> Инсталаторът работи само 24 часа след качването. Ако си разархивирал файловете по-рано, създай празен файл
> `install.unlock` до `index.php` и презареди.
